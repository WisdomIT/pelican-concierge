# 카탈로그: 고급 항목

카탈로그 항목에서 이름·egg·크기·질문이 아닌 것은 전부 YAML 한 칸에 들어갑니다. 이 문서는
각 키가 무엇을 하고, 어떤 형태여야 하고, 적지 않으면 어떻게 되는지를 적은 것입니다.

**모든 키는 선택입니다.** 쓰지 않는 것은 적지 않아도 됩니다.

편집기는 여기 적힌 형태와 **고른 egg** 양쪽에 맞춰 검사합니다. 그래서 변수 이름을 잘못
쓰거나 형태가 어긋나면 저장하기 전에 알려줍니다 — 누군가 서버를 만들려다 실패할 때가
아니라.

---

## 접속자 수

### `query`

*문자열 · `minecraft_java` · `minecraft_bedrock` · `source` · `goldsrc` · `cfx` · `palworld` 중 하나*

이 게임에게 접속자 목록을 어떤 프로토콜로 물어볼지입니다. 에이전트는 이 수치로 "지금 몇 명
있어?"에 답하고, 서버가 놀고 있는지 판단합니다.

**[Player Counter](https://hub.pelican.dev/plugins/player-counter) 플러그인이 필요합니다.**
없으면 이 키는 무시됩니다 — 접속자 수를 알 수 없고, 유휴 판정은 네트워크 사용량을 보는
방식으로 물러납니다.

쿼리 프로토콜이 없는 게임은 적지 않으면 됩니다. 그때도 같은 방식으로 물러납니다.

```yaml
query: minecraft_java
```

### `query_port_variable`

*문자열 · egg 변수 이름*

게임이 항상 접속 포트로 쿼리에 답하지는 않습니다. 쿼리용 포트가 egg 변수에 들어 있으면
그 변수 이름을 여기 적습니다. 그러면 주 포트 대신 그 값을 씁니다.

적지 않으면 서버의 접속 포트로 물어봅니다.

```yaml
query_port_variable: QUERY_PORT
```

## 사용자에게 주어지는 것

### `player_var`

*문자열 또는 `null`*

최대 인원이 담기는 egg 변수입니다. 사용자가 크기를 고르면 그 크기의 인원 수가 이 변수에
들어갑니다.

게임에 **그런 변수가 아예 없으면** `null` 이라고 **명시**하세요. 그러면 인원은 오직 배정된
자원(메모리·디스크·CPU)으로만 표현됩니다 — 마인크래프트가 그렇습니다. `null` 을 적는 것은
"확인했고 없다"는 기록이고, 키를 통째로 빼면 아무 말도 안 한 것입니다.

값은 [`caps`](#caps) 에 상한이 있으면 그 값으로 깎입니다.

```yaml
player_var: MAX_PLAYERS
```

### `caps`

*키-값 묶음 · egg 변수 이름 → 정수*

변수의 상한입니다. 크기에서 온 값이든 사용자가 직접 답한 값이든 상관없이 적용되고, 넘으면
egg 에 넘기지 않고 이유를 들어 거절합니다.

egg 규칙은 대개 무엇도 지켜주지 못할 만큼 헐겁기 때문에 필요합니다. `MAX_PLAYERS` 의 규칙이
`min:1` 뿐이면 10000 도 그대로 통과하고, 서버는 사람이 몰린 첫 저녁에 죽습니다.

```yaml
caps:
  MAX_PLAYERS: 32
```

### `defaults`

*키-값 묶음 · egg 변수 이름 → 한 줄짜리 값*

사용자에게 묻지 않고 개설 때 그대로 넣을 값입니다. 답이 하나로 정해지는 항목에 써서 대화가
그걸 묻지 않게 합니다.

값은 **한 줄짜리**여야 합니다 — 문자열·숫자·참거짓. 목록이나 중첩 블록은 안 됩니다. 환경
변수에 그대로 들어가기 때문입니다.

```yaml
defaults:
  BUILD_NUMBER: latest
  SERVER_JARFILE: server.jar
```

## 포트

### `ports`

*키-값 묶음*

이 게임이 포트를 몇 개 쓰고, 그 포트로 무엇을 하는지입니다.

| 키 | 형태 | 하는 일 |
|---|---|---|
| `count` | 1 이상의 정수 | 잡을 포트 수. **필수** |
| `protocol` | `tcp` · `udp` 의 목록 | 그 포트가 허용해야 하는 프로토콜 |
| `contiguous` | `true` / `false` | 참이면 잡는 포트가 **연속**이어야 합니다 — 게임이 다음 포트를 스스로 여는 경우에 씁니다. 기본 `false` |
| `derive` | 목록 | 남는 포트를 egg 변수에 넣습니다(아래) |

`derive` 의 각 항목:

| 키 | 형태 | 하는 일 |
|---|---|---|
| `env` | 문자열 | 포트를 넣을 egg 변수 |
| `from` | `allocation` | 포트의 출처. 지금은 `allocation` 뿐입니다 |
| `index` | 0 부터의 정수 | 몇 번째 포트인지. `0` 이 주 포트이므로 추가 포트는 `1` 부터입니다 |

`index` 가 `count` 보다 작지 않으면 **잡지도 않은 포트**를 가리키는 것입니다. 편집기가 이를
잡아 줍니다 — 그러지 않으면 개설이 실패하는데 설명할 단서가 없습니다.

```yaml
ports:
  count: 3
  protocol: [udp]
  contiguous: true
  derive:
    - { env: QUERY_PORT, from: allocation, index: 1 }
    - { env: RCON_PORT, from: allocation, index: 2 }
```

## 비밀 값

### `secrets`

*egg 변수 이름의 목록*

모델에게 절대 가면 안 되는 값입니다. 콘솔 한 줄·설정 파일·설치 로그에 이 값이 나오면
보내기 전에 지웁니다.

**플러그인이 필요 없습니다** — 이 플러그인이 직접 가립니다.

이름 패턴 안전망(`PASSWORD`·`TOKEN`·`_KEY` 등)이 있지만 그건 최후의 방어선이지 선언을
대신하지 않습니다. 이름에 드러나지 않는 비밀은 놓치고, 게임별로 무엇이 비밀인지 아는 곳은
카탈로그뿐입니다. egg 에 비밀로 보이는 변수가 있는데 선언하지 않았으면 편집기가 알려줍니다.

> ⚠ **가리는 것과 저장은 다릅니다.** 여기 적으면 값이 대화에 안 나올 뿐, 암호화되지는
> 않습니다. 값은 여전히 `server_variables` 에 남아 패널 운영자가 볼 수 있습니다. 암호화해
> 두려면 [Secret Variables](https://github.com/WisdomIT/pelican-secret-variables) 플러그인에서
> 그 변수를 *managed* 로 표시해야 하고, 이는 여기 적는 것과 별개의 결정입니다.

```yaml
secrets: [SERVER_PASSWORD, ADMIN_PASSWORD]
```

## 모드

### `mods`

*키-값 묶음*

이 게임이 모드를 받는지, 어떤 방식인지입니다. 에이전트는 이 값으로 **무엇이 가능한지
설명**합니다 — 이 값만으로 무언가를 설치하지는 않습니다.

| 키 | 형태 | 하는 일 |
|---|---|---|
| `supported` | `true` / `false` | 모드가 가능하기는 한지 |
| `kind` | `plugin` · `mod` · `addon` · `workshop_id` · `resource` · `config_ini` 중 하나 | 모드가 서버에 닿는 방식(아래) |
| `path` | 문자열 | 파일을 쓰는 방식일 때 모드가 놓이는 경로 |
| `note` | 문자열 | 에이전트가 그대로 전할 한 문장 — 사용자가 무엇을 해야 하는지 |
| `config_path` | 문자열 | `config_ini` 용 — 모드 목록이 적힌 파일 |
| `keys` | 키-값 묶음 | `config_ini` 용 — 어느 설정이 무엇을 담는지 |

각 `kind` 의 뜻:

- **`plugin`** — 디렉터리에 넣는 서버 플러그인 (마인크래프트 Paper, 러스트 oxide)
- **`mod`** — 본래 의미의 모드. 대개 클라이언트도 맞춰야 합니다 (Fabric, Forge, 팩토리오)
- **`addon`** — 소스 엔진 계열의 애드온 (개리모드)
- **`workshop_id`** — egg 변수에 워크숍 id 를 넣어 고르는 방식
- **`resource`** — 폴더에 넣는 리소스 (FiveM)
- **`config_ini`** — 파일을 복사하는 게 아니라 ini 를 고쳐 켜는 방식

모드를 **검색·설치**하려면
[Minecraft Modrinth](https://hub.pelican.dev/plugins/minecraft-modrinth) 또는
[Rust uMod](https://hub.pelican.dev/plugins/rust-umod) 플러그인이 필요합니다. 없으면 에이전트는
"이 게임은 모드를 못 쓴다"고 말하는 대신 **관리자가 그 플러그인을 설치해야 한다**고
안내합니다.

```yaml
mods:
  supported: true
  kind: plugin
  path: plugins/
  note: 패널의 Modrinth 탭에서 설치할 수 있습니다
```

## 설치 직후

### `post_install`

*목록*

설치가 끝난 뒤, 사용자에게 "준비됐다"고 알리기 **전에** 자동으로 처리할 일입니다. 플레이어가
알 필요조차 없어야 하는 것들에 씁니다.

각 절차에는 `type` 이 있고, 그 종류가 나머지 필수 키를 정합니다.

**`file_replace`** — 파일 안의 글자를 바꿉니다.

| 키 | 형태 | 필수 |
|---|---|---|
| `path` | 문자열 — 서버 안 경로 | 예 |
| `from` | 문자열 — 찾을 내용 | 예 |
| `to` | 문자열 — 대신 넣을 내용 | 예 |
| `reason` | 문자열 — 왜 필요한지 | 아니오, 그래도 적으세요 |

**`json_vmarg`** — JSON 실행 파일의 JVM 인자를 서버 메모리에 맞춰 설정합니다.

| 키 | 형태 | 필수 |
|---|---|---|
| `path` | 문자열 — 서버 안 경로 | 예 |
| `arg` | 문자열 — 인자, 예: `-Xmx` | 예 |
| `value_ratio` | 0 과 1 사이의 수 — 메모리 제한 대비 비율 | 예 |
| `reason` | 문자열 | 아니오, 그래도 적으세요 |

```yaml
post_install:
  - type: file_replace
    path: eula.txt
    from: eula=false
    to: eula=true
    reason: 동의하기 전에는 첫 기동이 조용히 실패한다
  - type: json_vmarg
    path: ProjectZomboid64.json
    arg: -Xmx
    value_ratio: 0.62
    reason: egg 가 -Xmx8g 를 하드코딩해 컨테이너가 죽인다
```

## 설치와 이미지

### `install_min_mb`

*정수 — 메가바이트*

설치가 끝났을 때의 대략적인 용량입니다. 패널은 **중간에 끊긴 설치도 installed 로 표시**하기
때문에, 용량이 무언가 잘못됐다는 유일한 단서인 경우가 많습니다. 그 판단을 위해 적어 둡니다.

```yaml
install_min_mb: 4000
```

### `java_from`

*문자열 — egg 변수 이름*

게임 버전이 담긴 변수를 알려줍니다. 버전이 필요한 런타임을 정하는 게임에 씁니다. 두 곳에서
쓰입니다:

- **도커 이미지** — 그 변수에서 버전을 읽어 맞는 Java 이미지를 고릅니다. 이게 없으면 egg 의
  기본 이미지가 쓰이는데, 사용자가 고른 버전과 안 맞을 수 있습니다
- **서버 이름** — 버전이 있는 게임은 "마인크래프트 4인" 대신 "마인크래프트 1.21" 로 짓습니다

```yaml
java_from: MINECRAFT_VERSION
```

### `image`

*문자열 — 도커 이미지 태그*

버전이 이미지를 정하지 않는 경우에 쓸 고정 이미지입니다. `java_from` 이 있으면 무시됩니다.
둘 다 없으면 egg 기본값을 씁니다.

## 사람에게 전할 말

### `notes`

*문자열 목록*

사용자에게 알려줄 만한 것을 그들의 말로 적습니다. **첫 번째 항목이 개설 카드에 보이므로**
가장 먼저 알아야 할 것을 맨 앞에 두세요 — 긴 설치 시간, 직접 준비해야 하는 라이선스, 멈춘
것처럼 보이지만 정상인 첫 기동 같은 것들입니다.

```yaml
notes:
  - 첫 기동에 10분 넘게 걸립니다. 멈춘 게 아닙니다.
```

### `verified`

*키-값 묶음*

이 게임을 실제로 시험했을 때 **관찰한 것**입니다. 코드가 읽지는 않습니다 — 다음에 이 항목을
고칠 사람에게 "정상이란 이런 모습이었다"를 남기는 기록입니다.

| 키 | 뜻 |
|---|---|
| `install` | 설치가 끝났을 때의 모습 — 용량, 소요 시간 |
| `boot` | 정상적인 첫 기동의 모습 |

```yaml
verified: { install: "5.8GB", boot: "맵 생성 진행, RCON 28016 바인드" }
```
